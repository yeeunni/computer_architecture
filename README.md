<h3>Project #0</h3>
<p>1. Logisim으로 간단한 회로를 구현한다. transmission gates를 이용해 MUX를 만들고, MUX를 이용해 LATCH를 만든다.

비동기 카운터가 드물게 사용되는 이유는 clk가 독립적으로 작동할 시, 시간 지연이나 추적오류가 발생할 가능성이 있기 때문이다.
